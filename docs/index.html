Zero-Config Embedded Tectonic Engine

Traditional TeX distributions like MacTeX and TeX Live take 5+ GB and hours of fragile Perl script configuration. Tiya packages the modernized Rust-based Tectonic engine directly inside the app. It automatically downloads required CTAN packages on first build, then caches them offline forever.

ENGINE tectonic --keep-intermediates --outdir .build thesis.tex

100% Private by Default

macOS Security Notice (Un-notarized Build)

Because Tiya is currently free and open source without an Apple Developer certificate, macOS Gatekeeper may show a “Tiya is damaged and can't be opened” warning. You can clear this attribute with a single terminal command:

xattr -cr /Applications/Tiya.app
